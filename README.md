## Очередь через два стека (TwoStacksQueue)

### Постановка задачи

Реализовать очередь (FIFO) с помощью двух стеков (LIFO).  
Обязательное требование: добавить проверку на переполнение – при попытке добавить элемент в полностью заполненную очередь должен удаляться самый старый элемент, а новый элемент добавляется в конец. Такой механизм называется перезаписью последнего элемента.

### Пояснения к коду

В предоставленном коде создан класс `TwoStacksQueue`, который внутри использует два списка Python:

- `stack_push` – стек для добавления новых элементов (при вызове `enqueue`).
- `stack_pop` – стек для извлечения элементов (при вызове `dequeue` или `front`).

### Основные методы

| Метод       | Действие                                                                                     |
|-------------|----------------------------------------------------------------------------------------------|
| `enqueue(x)`| Добавляет элемент `x` в конец очереди. Если задан `max_size` и очередь уже полна – предварительно удаляет самый старый элемент через `dequeue()`. |
| `dequeue()` | Удаляет и возвращает первый элемент очереди. Если очередь пуста – возвращает `None`. |
| `front()`   | Возвращает первый элемент без удаления. Если очередь пуста – возвращает `None`.              |

### Ключевой принцип работы двух стеков

Очередь имитируется за счёт **ленивого перекладывания** элементов из `stack_push` в `stack_pop`:

- При `enqueue` элемент всегда кладётся в `stack_push` (операция O(1)).
- При `dequeue` или `front`:
  - Если `stack_pop` не пуст – верхний элемент этого стека является головой очереди (берётся или просматривается за O(1)).
  - Если `stack_pop` пуст – все элементы из `stack_push` перекладываются в `stack_pop` (при этом порядок элементов меняется на противоположный, что восстанавливает FIFO). После этого голова оказывается на вершине `stack_pop`.

Такая схема даёт амортизированное время O(1) на каждую операцию.

### Реализация перезаписи при переполнении

В конструкторе задаётся необязательный параметр `max_size` (по умолчанию `None` – нет ограничения).  
В методе `enqueue` перед добавлением нового элемента выполняется проверка:
если max_size указан и текущий размер очереди == max_size:
вызвать dequeue() # удалить голову
Таким образом, при попытке добавить элемент в уже заполненную очередь сначала удаляется самый старый элемент, а затем новый добавляется в хвост. Размер очереди остаётся равным `max_size`, а старый элемент «перезаписывается» новым.

### Проведённые тесты

Тесты выполнены на очереди с максимальным размером 3.

```python
q = TwoStacksQueue(3) # очередь вместимостью 3 элемента
q.enqueue('A')
q.enqueue('B')
q.enqueue('C')
print(q.front()) # ожидаем 'A' – первый добавленный
q.enqueue('D') # переполнение, удаляется 'A', добавляется 'D'
print(q.dequeue()) # ожидаем 'B'
print(q.dequeue()) # ожидаем 'C'
print(q.dequeue()) # ожидаем 'D'
```
